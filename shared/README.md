# shared/

> Contracts and constants shared between `backend/` and `mobile/`.
> Last updated: 2026-09-24 | Owner: Fuad (both agents co-read)

---

## Structure

```
shared/
├── contracts/          Files generated by the backend, consumed by mobile
│   ├── openapi.yaml    API spec (AUTO-GENERATED — do not hand-edit)
│   ├── error-codes.json  Mirror of backend error codes enum
│   ├── bank-codes.json   Canonical bank list + adapter metadata
│   └── roles.json        Role definitions + permission matrix
└── constants/          Human-maintained constants used by both sides
    ├── packages.json   Subscription package definitions (prices in santim)
    └── countries.json  Supported countries (Ethiopia only for MVP)
```

---

## Rules

### contracts/ — never hand-edit
- `openapi.yaml` is generated by `cd backend && npm run swagger:export`.
- `error-codes.json` is generated by `cd backend && npm run export:error-codes`.
- Hand edits will fail the `shared-ci.yml` CI check.

### constants/ — human-maintained
- Edit `packages.json` when Fuad changes pricing.
- Both backend (seed) and mobile (pricing screen) read `packages.json`.
- All prices in `priceMinor` (integer santim). 199.00 ETB = `19900`.

### Adding a new bank
1. Implement the adapter in `backend/src/verification/adapters/{code}/`.
2. Add the bank entry to `shared/contracts/bank-codes.json`.
3. Add the bank logo PNG to `mobile/assets/banks/{code}.png`.
4. Add localized bank name to both `app_en.arb` and `app_am.arb`.
5. Regenerate `openapi.yaml` (`npm run swagger:export`).
6. All in one PR.

### Adding a new package
1. Edit `shared/constants/packages.json`.
2. Update the seed script (`backend/prisma/seed.ts`).
3. Update the pricing screen in mobile.
4. All in one PR.

## Import patterns

### Backend (TypeScript)
```ts
import bankCodes from '../../shared/contracts/bank-codes.json';
import packages from '../../shared/constants/packages.json';
```

### Mobile (Dart)
Generated client from openapi.yaml is at `mobile/lib/api/generated/`.
Constants are loaded at runtime or code-generated via build_runner.
