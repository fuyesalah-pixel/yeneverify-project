| Key/behavior | Local development | Staging | Production |
|---|---|---|---|
| `NODE_ENV` | `development` | `staging` | `production` |
| `LOG_LEVEL` | `debug` | `info` | `warn` |
| Database | Docker PostgreSQL | Hostinger managed PostgreSQL | Hostinger managed PostgreSQL |
| Redis | Docker Redis | Hostinger Redis | Hostinger Redis |
| R2 | MinIO via `R2_USE_MINIO=true` | Cloudflare R2 staging bucket | Cloudflare R2 production bucket |
| AfroMessage | deterministic mock | real sandbox key | real production key |
| Vision OCR | deterministic mock | GCP staging project | GCP production project |
| FCM | disabled/mock | real staging project | real production project |
| Sentry | disabled by empty DSN | staging DSN | production DSN |
| Throttle | relaxed local override (`THROTTLE_LIMIT=1000`) | real values | real values, stricter OTP limit |
| JWT keys | development key | staging key | production key, different from staging |
| Bank adapters | mock registry | real, low concurrency | real, configured concurrency |
| Feature flags | all MVP flags on | conservative | conservative |

## Injection rules

- Local: copy `docker/.env.example` to `docker/.env`; `bootstrap.sh` passes it to Compose.
- Local backend: copy `backend/.env.example` to `backend/.env`; NestJS loads dotenv only for this local workflow.
- Staging/production: inject values through Hostinger. Never copy a production `.env` into the repository.
- Hosted `APP_URL`, `CORS_ORIGINS`, `R2_ENDPOINT`, and `R2_PUBLIC_BASE_URL` must be real HTTPS endpoints; localhost and wildcards are rejected in production.
- File-backed credentials use read-only mounts under `/run/secrets`; environment values contain paths, not JSON contents.
- `FCM_PRIVATE_KEY_FILE` takes precedence over the escaped `FCM_PRIVATE_KEY` value when a file mount is configured.
- Run `./scripts/check-env-sync.sh` after changing the example or schema.

See [rotation.md](rotation.md), [secrets.md](secrets.md), and [deploy.md](deploy.md) for operational policy.
