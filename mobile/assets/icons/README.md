# assets/icons/

Custom SVG icons not available in the Lucide icon set.

## When to add here
Only add an icon here if it does NOT exist in Lucide (https://lucide.dev).
Always prefer Lucide icons first (zero bundle cost, already a dependency).

## Rules
- SVG only, 24×24 viewBox, 1.75px stroke.
- No fill — stroke only (matches Lucide style).
- Optimize with svgo before committing.
- Name: `ic_{name}.svg` in snake_case.
- Max 4KB per icon.
