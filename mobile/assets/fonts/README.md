# assets/fonts/

Place font files here. Required files:

## Inter (primary — all UI text)
Download from: https://rsms.me/inter/ (variable font or static files)

- `Inter-Regular.ttf`    (weight 400)
- `Inter-Medium.ttf`     (weight 500)
- `Inter-SemiBold.ttf`   (weight 600)
- `Inter-Bold.ttf`       (weight 700)

## Noto Sans Ethiopic (Amharic locale only)
Download from: https://fonts.google.com/noto/specimen/Noto+Sans+Ethiopic

- `NotoSansEthiopic-Regular.ttf`   (weight 400)
- `NotoSansEthiopic-Medium.ttf`    (weight 500)
- `NotoSansEthiopic-SemiBold.ttf`  (weight 600)
- `NotoSansEthiopic-Bold.ttf`      (weight 700)

## Rules
- No font files > 2MB each.
- Noto Sans Ethiopic is loaded only when `am` locale is active.
- Do NOT add any other font without approval from Fuad.
- Both fonts are declared in `pubspec.yaml` under `flutter.fonts`.
